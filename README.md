# I-Mage

**Stage 1 — work in progress.** Семантический поиск по фотографиям на своём компьютере.

## Задумка

Локальное приложение для навигации по личной медиатеке: индексировать фото, строить эмбеддинги (CLIP) и искать снимки по текстовому описанию — «кот на диване», «закат на море» и т.п.

Долгосрочно — персистентный индекс, поиск по примеру изображения, другие ML-модули (лица, сцены, видео). Полное видение: [docs/goal.md](docs/goal.md).

## Сейчас

Текстовый запрос → CLIP-эмбеддинг → сравнение с фото в каталоге → top-k лучших совпадений. Поиск **на лету** (без сохранённого индекса); для больших библиотек нужен `limit`.


## Быстрый старт

```bash
conda activate ml-env
uvicorn api.app:app --reload
```

Открыть http://127.0.0.1:8000 

Опционально: каталог с фото через `IMAGE_SEARCH_DIR`, датасет для тестов — `python scripts/download_data.py`.
